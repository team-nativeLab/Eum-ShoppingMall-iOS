# Eum ShoppingMall iOS

이음산업건설 쇼핑몰 iOS 앱입니다. Swift, UIKit, SwiftUI, MVVM, Tuist를 기반으로 구성합니다.

## 시작하기

```sh
tuist generate
open EumShoppingMall.xcworkspace
```

현재 저장소는 초기 개발 환경 단계입니다. Figma 분석과 실제 화면 구현은 별도 작업으로 진행합니다.

자세한 협업 규칙은 [CONVENTION.md](CONVENTION.md)와 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.
