# A-09c 현금영수증 결제 상태 패리티 기록

- Figma: `557:5906` (390 × 1375 pt)
- 증빙 서류에서 현금영수증을 선택하면 소득공제용/지출증빙용 선택과 식별번호 입력 패널을 표시한다.
- 결제수단 카드를 56 pt, 섹션 제목을 48 pt, 현금영수증 패널을 192 pt로 맞추고 결제 금액 요약의 20 pt inset과 강조 금액 크기를 Figma 측정값에 맞췄다.
- 소득공제용 휴대폰 번호를 기본 선택하고, 입금 확인 후 발급 안내를 표시한다.
- 현금영수증을 선택한 경우 식별번호 입력이 유효해야 결제할 수 있다. 지출증빙용은 사업자등록번호 10자리 입력을 받는다.
- 연락처·현금영수증 발급은 서비스 연동 전의 로컬 Mock 상태다.
- 시뮬레이터에서 이 선택 상태를 직접 열어 캡처하지 못해 화면별 시각 비교는 미검증이다.
