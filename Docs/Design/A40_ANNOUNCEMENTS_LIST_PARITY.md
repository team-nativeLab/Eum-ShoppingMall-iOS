# A-40 공지사항 목록

- Figma: [A-40 공지사항 목록](https://www.figma.com/design/N3Ic9TfSnUBVMgAuayBVly?node-id=657-35718)
- Node: `657:35718` (390 × 844 pt)
- 앱 진입: 회원/비회원 마이페이지 > 공지사항
- Figma prototype의 뒤로 가기 대상은 회원 마이페이지(`213:3368`)입니다. 이 Node는 A-42 고객센터(`661:8066`)와 다른 화면입니다.
- 첫 번째 고정 공지 행은 상세 화면 열기 반응이 있으며, 현재 A-41 상세 화면으로 연결됩니다.

## 화면 구성

상단 제목과 뒤로 가기, 고정 공지 2개, 일반 공지 5개, 각 행의 날짜와 Figma에 표시된 하단 로딩 표시를 구현했습니다. 긴 제목은 한 줄 말줄임으로 표시합니다. 공지 목록은 화면 디자인을 위한 Mock 데이터이며, 로딩 표시는 Figma 캡처 상태를 재현합니다. 페이지네이션이나 서버 통신은 구현하지 않았습니다.

## 시각 확인

`Docs/Screenshots/A40-announcements-list.png`는 iPhone 17 Pro 시뮬레이터 캡처입니다. 검증용 clone에서 공지 목록을 앱 시작 화면으로 열었습니다. 이 임시 진입 코드는 작업 브랜치에 포함하지 않았습니다. 기기 해상도와 Figma의 390 × 844 pt frame 차이로 픽셀 일치 여부는 주장하지 않습니다.
