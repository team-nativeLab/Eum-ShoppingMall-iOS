# A-32z 알림 빈 상태 패리티 기록

- Figma: `480:5756` (390 × 844 pt)
- 기존 알림 화면과 같은 TopBar를 사용하고, 알림 배열이 비었을 때 목록 요약·행·보관 안내를 빈 상태 콘텐츠로 대체한다.
- 빈 상태는 본문 상단 80 pt, 좌우 20 pt inset, 아이콘 배경 64 × 64 pt, 내부 상단 64 pt로 배치한다.
- 제목은 Noto Sans KR Bold 18 pt / 26 pt line height, 설명은 Regular 14 pt / 20 pt line height이며 기존 디자인 토큰을 재사용한다.
- 화면 렌더 이미지에는 종 모양 아이콘이 보이고 `get_design_context` 코드와 하위 레이어 이름은 `search-x`로 표시된다. 기존 `TopBarBell` 에셋은 렌더 이미지와 일치해 그대로 재사용했다.
- 시뮬레이터 UI에서 이 상태를 직접 열어 비교한 스크린샷은 확보하지 못했다. 빌드 및 앱 실행은 검증하되 화면별 런타임 패리티는 미검증으로 남긴다.
- 데이터 연결 전 상태를 검증할 수 있도록 ViewModel에서 빈 알림 배열 주입을 지원하고 Preview에서 사용한다.
