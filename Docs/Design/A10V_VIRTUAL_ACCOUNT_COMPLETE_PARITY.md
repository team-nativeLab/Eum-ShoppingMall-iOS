# A-10v 가상계좌 주문 완료 패리티 기록

- Figma: `557:5483` (390 × 970 pt)
- 선택된 결제수단을 결제 완료 흐름에 전달해 가상계좌 주문의 완료 상태를 분기한다.
- 입금 은행, 계좌번호, 예금주, 입금 금액, 기한을 Mock 정보로 표시하고 계좌번호 복사 버튼을 제공한다.

- 은행 계좌·주문 정보는 서비스 연결 전 디자인용 Mock 값이다.
- 시뮬레이터에서 결제 선택과 완료 라우트를 직접 조작해 캡처하지 못해 화면별 시각 비교는 미검증이다.
