## 새 페이지보다 서비스·콘텐츠 결정이 먼저인 항목

- **로그인·가입·이메일/비밀번호/휴대폰 인증**: 현재 목업/오류 표현이며 인증 제공자·서버 계약이 필요하다. 가입 성공은 로그인으로 돌아갈지 결과 화면을 둘지 결정해야 한다. A-13e 등 기존 오류 프레임과 성공 인증을 구분한다.
- **결제·취소·반품 접수·재주문·영수증·거래명세서·첨부 다운로드**: 실제 주문/결제 API, 상품 식별자, 파일 URL 및 권한이 필요하다. 현재 서버 처리 성공으로 간주하지 않는다. PDF는 시스템 뷰어로 충분한지, 전용 화면이 필요한지 결정한다.
- **고객센터 전화·견적 담당자 연락·회사 지도**: 현재 `0000-0000`, 임시 주소 등이므로 검증된 연락처와 주소가 필요하다.
- **약관의 오래된 버전·개정 원문**: 현재/이전/개정 예정 고지 화면과 선택 UI는 존재한다. 현재 퍼블리싱은 사용자 지시에 따라 Figma의 본문 자리표시자와 날짜를 그대로 사용한다. 실제 버전 ID·시행일·원문 적용은 후속 서비스 작업이며, 이번 연결 작업의 블로커가 아니다.
- **알림 → 정확한 레코드**: 현재 알림에는 주문/문의/공지 대상 ID가 없다. 기존 종류별 목록으로 연결했다. 특정 상세로 바로 가려면 대상 ID와 대상 삭제/접근 불가 처리 계약이 필요하다.
- **재견적 폼**: 기존 견적 문의 화면으로 연결했다. 기존 견적의 정확한 상품/옵션/수량·원문 복사나 원 견적과의 연결은 조회/접수 데이터 계약이 필요하다. 현재 새 목업 폼을 연다.
- **범용 로딩/오류/재시도·인증 만료·접근 불가**: 일부 빈/오류 프레임은 있으나 앱 전반 공통 디자인은 인벤토리로 확정할 수 없다. 공통 상태 디자인의 필요 범위를 정한다.
