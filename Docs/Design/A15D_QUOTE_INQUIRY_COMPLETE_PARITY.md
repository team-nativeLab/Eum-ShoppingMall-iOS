# A-15d 견적 문의 접수 완료 패리티 기록

- Figma: `557:5389` (390 × 844 pt)
- 견적 문의 폼에서 필수 입력 검증을 통과한 뒤 완료 화면으로 전환한다. 서버 연동 전이므로 접수 응답은 Mock이다.

- 시뮬레이터에서 이 모달 완료 상태를 직접 열어 캡처하지 못해 화면별 시각 비교는 미검증으로 남긴다.
