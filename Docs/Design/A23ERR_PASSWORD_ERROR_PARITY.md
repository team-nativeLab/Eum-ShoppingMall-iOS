# A-23-err 비밀번호 오류 패리티 기록

- Figma: `528:21835` (390 × 844 pt)
- 기존 내 정보 확인 화면의 레이아웃과 공통 컴포넌트를 사용한다.
- 비어 있지 않은 Mock 비밀번호가 테스트용 유효 값(`password`)과 다르면 비밀번호 필드에 1.5 pt 위험 색상 테두리와 기존 원형 경고 에셋, 인라인 오류 안내를 표시한다.
- 사용자가 다시 입력하기 시작하면 오류 표시는 지우며, 빈 값은 기존 입력 안내 경로를 유지한다.
- 오류 화면 Preview와 ViewModel 테스트를 추가했다. 실제 인증 API는 현재 범위 밖이다.
- 시뮬레이터에서 해당 라우트를 열어 캡처하는 기능은 이 환경에서 제공되지 않아 직접 시각 비교는 미검증이다.
