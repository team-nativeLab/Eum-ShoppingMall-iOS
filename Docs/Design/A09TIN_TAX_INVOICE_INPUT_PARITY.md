# A-09t-in 세금계산서 직접 입력 패리티 기록

- Figma: `557:5727` (390 × 1615 pt)
- 세금계산서 증빙에서 사업자 정보 변경을 누르면 결제 화면 안의 직접 입력 양식으로 전환한다.
- 사업자등록번호, 상호, 대표자명, 수신 이메일 필드를 구현하고 기존 checkout 하단 결제 버튼과 결제 단계 레이아웃을 유지한다.
- 사업자등록번호는 숫자 10자리만 입력되며, 직접 입력 상태에서는 필수 필드와 이메일 형식이 유효하고 주문 동의가 켜져야 결제할 수 있다.
- 실제 세금계산서 신청/회원 정보 저장은 Mock 범위 밖이다.
- 시뮬레이터에서 결제 화면의 직접 입력 상태를 직접 열어 캡처하지 못해 화면별 시각 비교는 미검증이다.
